# SEO Checklist for Every Blog Post

Every generated post MUST pass all of these checks before it's considered ready.

## Title & Meta

- [ ] Title includes primary keyword
- [ ] Title is under 60 characters
- [ ] Title uses power format: "[Keyword]: [Benefit/Hook]"
- [ ] Excerpt (meta description) is 150-160 characters
- [ ] Excerpt includes primary keyword
- [ ] Excerpt has a compelling hook (not just a summary)
- [ ] Slug is clean, keyword-rich, lowercase, hyphenated, no stop words

## Content Structure

- [ ] Primary keyword appears naturally within the first 100 words
- [ ] 3-7 H2 sections that break the post into scannable chunks
- [ ] H2s include secondary keywords where natural (don't force it)
- [ ] H3s used for sub-sections within longer H2 blocks
- [ ] At least one definition or key insight block for featured snippet potential
- [ ] Paragraphs are 2-4 sentences maximum
- [ ] No fluff paragraphs (every paragraph teaches or argues)
- [ ] Word count: 1,200-2,000 for support posts, 2,500+ for pillar posts

## Internal Linking

- [ ] Links to at least 2-3 other blog posts from the registry
- [ ] Links to the Data Room service page (/services/data-room/) at least once
- [ ] Links to a relevant case study if one exists for the topic
- [ ] Link text is descriptive (never "click here" or "read more")
- [ ] Backlink suggestions provided for existing posts that should link to this new one

## Authority & Credibility

- [ ] Includes 1-2 authority markers (80+ projects, $100MM+, $200MM market cap, etc.)
- [ ] References real examples (anonymized if needed)
- [ ] Includes a specific, actionable insight the reader can use immediately
- [ ] Doesn't over-claim or make promises about returns

## GEO / LLM Citation Optimization

- [ ] Opening paragraph is answer-first (40-60 words, directly answers the topic)
- [ ] No preamble or "In this article..." — the first paragraph IS the answer
- [ ] 3+ inline citations with external source links (industry reports, academic papers, official docs)
- [ ] 1+ expert quote with full name, title, and organization attribution
- [ ] 2+ statistics with explicit source attribution (never unsourced numbers)
- [ ] At least one named framework or methodology referenced by name
- [ ] Paragraphs are 40-60 words (optimized for LLM extraction)
- [ ] Each paragraph contains exactly one key insight (no compound paragraphs)
- [ ] Research brief consulted from `research-pipeline.mjs` output (if available)

## Brand Voice

- [ ] Tone is direct, confident, practical
- [ ] No banned phrases used (see voice-guide.md)
- [ ] Key phrases used where natural (not forced)
- [ ] Reads like a smart peer talking, not a blog post generated by AI
- [ ] No corporate speak, no fluff intros, no "in this article we will discuss..."
- [ ] Opening paragraph hooks the reader with a problem or contrarian take

## CTA

- [ ] Post ends with a natural, non-salesy call to action
- [ ] CTA matches the post topic (discovery call, template download, or audit)
- [ ] CTA feels like a helpful next step, not a sales pitch

## Frontmatter

- [ ] All required fields present (title, slug, publishedAt, updatedAt, excerpt, author, categories, tags, featured, image)
- [ ] Category matches a defined cluster category
- [ ] 3-5 tags that match the keyword cluster
- [ ] Image path follows convention: /images/blog/[slug]-hero.jpg
- [ ] Date is in YYYY-MM-DD format
- [ ] Author fields are complete and correct

## Post-Generation

- [ ] Registry updated with new post metadata
- [ ] Backlink suggestions noted
- [ ] Post assigned to correct output date folder
